# Assistente de Atendimento em Python

## Sobre o projeto

Este projeto consiste em uma automação simples de atendimento desenvolvida em Python. O programa analisa mensagens digitadas pelo usuário e classifica cada atendimento com base em palavras-chave predefinidas.

## Funcionalidades

- Recebe mensagens digitadas pelo usuário.
- Identifica palavras-chave no texto.
- Classifica atendimentos em categorias.
- Encaminha mensagens não identificadas para análise manual.

## Tecnologias utilizadas

- Python 3
- Estruturas condicionais (`if`, `elif` e `else`)
- Manipulação de strings

## Exemplo de funcionamento

**Entrada:**
"Olá, gostaria de saber o preço de uma landing page."

**Resultado:**
Categoria: Comercial
